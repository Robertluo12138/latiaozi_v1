# ali-latiao-writing — 阿里风格"拉条子"写作技能

将粗糙的中文月报、周报、项目复盘、数据分析结论、SQL 建表进度、BI 看板汇报、业务诊断改写为阿里管理者偏好的"拉条子"结构化写作。

本技能是**纯文本写作技能**：不写代码、不执行命令、不依赖任何脚本。

---

## 安装

将本目录放入 Claude Code 的 skills 目录。

**项目级（仅当前项目可用）**

```
<你的项目>/.claude/skills/ali-latiao-writing/
```

**用户级（全局可用）**

```
~/.claude/skills/ali-latiao-writing/
```

放置后，下次启动 Claude Code 即自动加载。无需额外配置、无需重启 IDE。

---

## 触发方式

直接用自然语言要求改写即可。常见触发表达：

- "把下面这段月报改成拉条子风格"
- "用阿里风格改写下面的周报"
- "结论先行，结构化重写下面的工作总结"
- "管理者风格汇报，把这段重写一下"
- "拉条子格式，老板要看的"

只要原文是中文工作汇报类内容，并出现"拉条子 / 阿里风格 / 结论先行 / 结构化 / 管理者 / 老板要看"等关键词之一，技能即被激活。

## 输出长什么样

每次输出严格遵循三层结构：

```
**[加粗总论点 1 条]**

**[加粗一级论点 1]**

- **[短判断无标点]：** 事实 + 数据 + 解释 + 判断。
- **[短判断无标点]：** 事实 + 数据 + 解释 + 判断。

**[加粗一级论点 2]**

- **[短判断无标点]：** ...
```

详细对照示例见 `references/examples.md`。

## 设计取舍

1. **纯文本技能**：不引入任何脚本或工具调用，避免维护成本。
2. **强制结构而非软建议**：拉条子的核心价值就在于结构稳定。本技能将"短判断无标点 / 字段名禁用 / 数据不得虚构"作为硬约束，不留松动余地。
3. **缺数据用占位符而非省略**：管理者最反感"等补完数据再回汇"。占位符 `待补充：XX数据` 让结构先成型，数据补回时只需局部替换。
4. **业务价值语言强制转换**：执行型同学最容易写成"做了什么"，技能强制改写为"做了什么对业务意味着什么"。
5. **12 项自检清单**：每次出稿前模型在脑中过一遍，避免常见返工点（字段名、虚构数据、口语化、客套）。

---

## 不做什么

- 不补充原文未提供的数据（数据缺失统一用 `待补充：XX数据`）
- 不输出客套开场与结尾感谢
- 不写 PPT、不画图、不生成代码
- 不主动建议改业务策略（仅按用户原文提到的方向给出"下一步动作"）
- 不替用户决策，仅替用户改写

---

## 自查触发是否成功

成功触发后输出应满足：

- 第一行是加粗总论点（不是"以下是改写"等过渡句）
- 每个二级条目前面那段加粗短判断**不含**任何 `,` `.` `;` `，` `。` `；` `、`
- 不出现 `**GMV：**` `**订单：**` 等字段名标签
- 数据全部来自原文，缺失处用 `待补充：XX数据`
- 全文不超过 800 字

如未满足，回到 `references/checklist.md` 逐项过。
