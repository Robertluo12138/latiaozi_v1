# 拉条子出稿前自检清单（12 项）

每次输出前**必须**逐条心算检查。任意一项不通过即返工，不得放行。

如需细则查证，回到 `style_rules.md`。

---

## 一、结构层级（3 项）

### ☐ 1. 是否有且仅有一条加粗总论点
- 在第一行
- 长度 12–28 字
- 包含"整体态势 + 关键结构判断"
- 不是流水账式的"本月做了 X / Y / Z"

### ☐ 2. 一级论点是否在 3–5 条之间
- 不得少于 3 条
- 不得多于 5 条
- 每条加粗
- 每条是结论式判断而非字段名
- 一级论点之间能形成"问题 → 抓手"的因果链

### ☐ 3. 每个一级下二级是否在 2–4 条之间
- 不得少于 2 条
- 不得多于 4 条

---

## 二、短判断合规性（4 项）

### ☐ 4. 短判断长度是否在 8–18 字之间
- ≤ 5 字：几乎一定是字段名，必返工
- 6–7 字：边界，建议加判断词扩展
- 19–22 字：边界，可放行
- ≥ 23 字：返工，应拆分或压缩

### ☐ 5. 短判断是否绝对不含禁用标点
逐字符扫描冒号前文字，确认不含：
`,` `.` `;` `，` `。` `；` `、`

特别注意：小数点（如 `0.8`）也是英文句号 `.`，必须挪到冒号后正文。

### ☐ 6. 短判断是否避开字段名形态

逐条比对反例：
- ❌ `GMV：` `订单：` `客单价：` `数据集：` `看板：` `SQL：`
- ❌ `本月数据：` `用户增长情况：` `经营情况：` 等"名词 + 情况/数据 + 冒号"
- ❌ 任何"名词 + 冒号"且不含动词/形容词/趋势词的形态

判定法：去掉冒号后能不能读出"判断"？读不出就是字段名。

### ☐ 7. 短判断是否压缩了"指标 + 态势 + 隐含判断"

逐条问自己：这句话本身有没有传递"是好是坏 / 是涨是跌 / 是稳是险"？

- ✅ `GMV 保持增长环比提升` —— 指标 + 态势 + 评价
- ✅ `订单规模增长但增速偏低` —— 指标 + 双向态势 + 隐忧
- ❌ `本月 GMV 情况` —— 仅时间 + 指标 + 占位词
- ❌ `订单数据` —— 仅指标

---

## 三、四要素铺陈（2 项）

### ☐ 8. 每段二级正文是否包含事实 / 数据 / 解释 / 判断

逐段拆解，确认四件事都能被指出。任一缺失即返工：

- 缺数据 → 用 `待补充：XX数据` 占位
- 缺解释 → 补一句结构性原因（"主要由 X 驱动" / "受 X 影响"）
- 缺判断 → 补一句对经营的意义或下一步含义（"反映 X 风险" / "应优先排查 X"）

### ☐ 9. 每段二级正文长度是否在 80 字以内

> 80 字基本意味着塞了过多信息或写成了流水账。建议拆分为两条二级，或压缩冗余表达。

---

## 四、内容真实性（1 项）

### ☐ 10. 是否绝对没有虚构数据

逐数字扫描，确认每个数字都来自用户原文：

- 原文写"涨了 10%" → 可写 `+10%`
- 原文写"涨了一些" → **不得**写 `+10%`，统一替换为 `待补充：环比变化`
- 原文写"还可以" / "差不多" / "蛮好" → 不可推断为任何具体数据

---

## 五、语气与冗余（2 项）

### ☐ 11. 是否避免口语 / 空泛副词 / 感叹号

逐句扫描，确认未出现：

- 口语："我们觉得 / 大概 / 应该 / 差不多 / 估计 / 感觉 / 蛮 / 挺 / 还行"
- 空泛副词（无数据支撑时）："非常 / 极大 / 巨大 / 显著 / 大幅 / 大量"
- 感叹号 `！` `!`
- emoji

### ☐ 12. 是否避免冗余开场白与结尾感谢

确认未输出：
- 开场："领导好" / "各位同事好" / "下面汇报"
- 结尾："以上" / "感谢领导审阅" / "请指正" / "汇报完毕"
- 过渡："接下来" / "下面" / "然后" / "另外"
- 推诿："限于篇幅" / "时间有限"

---

## 自检流程

1. 写完初稿
2. 逐项打钩（口算或在脑中逐项过）
3. 任一项不通过：定位到具体行 → 修改 → 重新打钩
4. 全部 12 项通过 → 输出
5. 不通过项 ≥ 3 时，回到 `style_rules.md` 重读对应小节再返工

---

## 快速诊断（出稿后看一眼）

读一遍自己的输出，问三个问题：

1. 一个事业部老板会前 30 秒扫一眼，能不能抓到核心结论？
2. 每条二级前面那句加粗，单独抽出来念，像不像一句话的判断？
3. 删掉所有数据后，结构与判断是否仍然成立？

三问都答"是"，可以放行。
