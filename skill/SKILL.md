# 阿里风格拉条子写作技能

## 何时使用

当用户提交中文工作汇报类原文，并希望改写为管理者会前可快速扫读的结构化写作时使用。

常见触发表达：
- "改成拉条子" / "阿里风格" / "结论先行"
- "重写月报 / 周报 / 复盘 / 总结"
- "结构化一下这个汇报"
- "管理者风格" / "老板要看的"

适用原文类型：月报、周报、项目复盘、数据分析结论、SQL/建表进度、BI看板汇报、业务诊断、经营分析。

## 输出层级（强制三层）

1. **总论点（1 条）** — 加粗。一句话点明本次汇报核心结论。
2. **一级论点（3–5 条）** — 加粗。每条是一句结论式判断（不是字段名）。
3. **二级子论点（每个一级下 2–4 条）** — 每条按下方强制格式书写。

## 二级子论点强制格式

```
**[短判断无标点]：** 事实 + 数据 + 解释 + 判断。
```

### 冒号前（短判断）硬约束

| 项 | 要求 |
|---|---|
| 长度 | 通常 8–18 个汉字 |
| 形态 | 结论式短句，不是字段名 |
| 禁用标点 | `,` `.` `;` `，` `。` `；` `、` 一律不得出现 |
| 禁用空标签 | `GMV：` `订单：` `客单价：` `数据集：` `看板：` `SQL：` 等单纯字段名一律不得作为短判断 |

判定法：去掉冒号后能不能读出"判断"？读不出就是字段名，必返工。

### 冒号后（正文）四要素

按顺序铺陈，可融合在 1–3 个完整中文句子内：

- **事实**：发生了什么动作 / 结果 / 现象
- **数据**：具体数字、占比、环比、同比、绝对值或区间
- **解释**：数据背后的原因 / 机制 / 结构性变化
- **判断**：对经营的意义、风险、或下一步含义

整段建议不超过 80 字。

## 业务价值语言（必做转换）

将"执行语言"改写为"业务价值语言"：

| 执行语言（不要） | 业务价值语言（要） |
|---|---|
| 建了一张订单宽表 | 订单宽表上线支撑多维经营分析 |
| 跑了一次 SQL | 完成订单回流校验数据一致性达标 |
| 上线了一个看板 | 经营看板上线管理层可日级追踪核心指标 |
| 优化了表结构 | 表结构治理后 BI 查询性能提升使用门槛降低 |
| 接了 N 个需求 | 完成 N 项业务分析需求支撑业务决策 |

## 缺数据时的处理（不得虚构）

若用户原文未给出具体数字 / 占比 / 环比同比：

- **绝对禁止**编造数据
- 使用占位符：`待补充：XX数据`
- 例：`本月订单 待补充：订单总数，环比 待补充：环比变化`

## 语气

- 克制、商务、扫读友好
- 不出现："我们觉得 / 大概 / 应该 / 差不多 / 估计 / 感觉"
- 不滥用："非常 / 极大 / 巨大 / 显著 / 大幅"（除非有具体数据支撑）
- 不出现感叹号 `！` `!`
- 不输出客套开场白与结尾感谢

## 工作流（按顺序执行）

1. **抽取**：从原文捞出所有事实、动作、数字、原因、风险、下一步
2. **归桶**：归入 3–5 个一级论点。常用归类范式：
   - 经营结果 / 经营动作 / 经营隐忧 / 后续动作
   - 进展 / 数据 / 风险 / 下一步
   - 业务问题 / 数据现象 / 根因判断 / 行动建议
3. **拟标**：为每条二级子论点拟一个 8–18 字短判断（无禁用标点、非字段名）
4. **填段**：用 1–3 句话补齐"事实 + 数据 + 解释 + 判断"
5. **回写总论点**：基于一级论点回写一句加粗总论点
6. **自检**：执行 `references/checklist.md` 12 项检查后再输出

## 输出长度

- 最终全文（不含原文回放）一般不超过 800 字
- 一级论点 ≤ 5 条
- 每个一级下二级 ≤ 4 条
- 单条二级正文 ≤ 80 字

## 完整输出形态示例（精简）

> **本月经营整体稳中有进结构性隐忧需提前修复**
>
> **经营结果环比改善但增长结构偏单点**
>
> - **GMV 保持增长环比提升：** 本月 GMV 2.3 亿，环比 +8%，盘子较上月扩大约 1700 万，说明经营动作对结果端有正向拉动。
> - **订单规模增长但增速偏低：** 本月订单 120 万，环比 +5%，低于 GMV 增速 3 个百分点，增长更多来自客单提升而非订单扩张。
>
> **经营隐忧需提前暴露**
>
> - **新客次月留存承压：** 次月留存 待补充：次月留存数据，仍处下行通道，反映拉新质量与承接动作之间存在断点，应优先排查首单后 7 日触达。
>
> **后续动作聚焦两件事**
>
> - **优先修复新客次月留存：** 立项次月留存专项，由用户增长团队负责，月底前完成首单后 7 日触达 + 14 日召回 SOP 落地。
> - **私域触达节奏对齐目标：** 私域运营节奏由月触达 2 次提升至 4 次，目标本月完成沉淀进度追平计划。

## 关键对照（再次强调）

**❌ 字段名式标签（禁止）**
> **GMV：** 本月GMV 2.3亿，环比增长8%。

**✅ 结论式短判断（要求）**
> **GMV保持增长环比提升：** 本月GMV 2.3亿，环比增长8%，整体经营规模较上月扩大，说明本月经营动作对结果有一定拉动。

**❌ 短判断含标点（禁止）**
> **订单同步增长，但低于GMV增速：** 本月订单120万，环比增长5%。

**✅ 短判断无标点 + 四要素齐备（要求）**
> **订单规模增长但增速偏低：** 本月订单120万，环比增长5%，低于GMV增速，说明增长不完全来自订单规模扩张，可能与客单提升或活动结构变化有关。
